# Party and Group Extras

Class icons and buff/title options for party and group windows.

Class icons for party and group members, plus options to hide buff icons, change their size and keep the title bar showing (in Party Options and the group window's options).

An add-on for [ROSE Mod Launcher](https://github.com/Zurnny/Rose_Mod_Launcher), for the game's **default** UI. The [Steampunk UI](https://github.com/Zurnny/SteamPunk) theme already includes this, so you don't need it with Steampunk (if both are on, Steampunk's files win).

## Install
1. Download this repo (Code > Download ZIP) and open it.
2. Copy the **Party and Group Extras** folder into `Launcher Mods` in your ROSE Online folder.
3. Open the launcher, press **Mods**, tick **Party and Group Extras**, and restart the game.

It updates itself from this repo whenever the launcher opens.

## Files it changes
- `Data/ui/themes/rose/game/arena_group.html`
- `Data/ui/themes/rose/game/party.html`
- `Data/ui/themes/rose/game/party_options.html`

Turning it off in the launcher puts the game's own files back.
